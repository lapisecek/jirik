## Postup pro Aiko
1. start_app(name="Word"). If Word is not installed, start_app(name="Poznámkový blok") (Notepad) instead.
2. Word shows a start page: click "Prázdný dokument" / "Blank document".
3. Click into the white page area and type the text the senior dictated (action type). Use only the senior's
   words; never invent personal data, addresses or numbers.
4. Bigger text for the senior: key ctrl+plus is zoom in Word as well (or the zoom slider bottom right).
5. Save: key ctrl+s, choose "Tento počítač"/"Dokumenty" if asked, type a short file name from the senior's
   words, press enter. Do not sign in to OneDrive or a Microsoft account - if asked, choose to save locally.
6. done: tell the senior in Czech the file name and that it is in Dokumenty.

## Pro seniora
1. Klikněte na tlačítko Start vlevo dole a napište „Word“. Klikněte na Word levým tlačítkem myši.
2. Klikněte na velký bílý obdélník „Prázdný dokument“.
3. Klikněte do bílé stránky a pište. Nový řádek uděláte klávesou Enter.
4. Uložíte to tak, že podržíte klávesu Ctrl vlevo dole a zmáčknete písmeno S.
5. Napište jméno dopisu a klikněte na „Uložit“. Dopis najdete ve složce Dokumenty.
